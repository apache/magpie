# Apache Magpie mailing lists

Apache Magpie uses public mailing lists for project discussions, questions,
and development coordination.
You can participate by email; a GitHub account is not required.
Please follow the [ASF Code of Conduct](https://www.apache.org/foundation/policies/conduct.html)
and remember that messages sent to public lists are archived.

## Public lists

| List | Purpose | Subscribe | Unsubscribe | Archives |
| --- | --- | --- | --- | --- |
| [dev@magpie.apache.org](mailto:dev@magpie.apache.org) | Development, project proposals, and release discussions | [Subscribe](mailto:dev-subscribe@magpie.apache.org) | [Unsubscribe](mailto:dev-unsubscribe@magpie.apache.org) | [dev archives](https://lists.apache.org/list.html?dev@magpie.apache.org) |
| [users@magpie.apache.org](mailto:users@magpie.apache.org) | Questions about using Magpie and sharing experiences | [Subscribe](mailto:users-subscribe@magpie.apache.org) | [Unsubscribe](mailto:users-unsubscribe@magpie.apache.org) | [users archives](https://lists.apache.org/list.html?users@magpie.apache.org) |
| [commits@magpie.apache.org](mailto:commits@magpie.apache.org) | Repository commit notifications | [Subscribe](mailto:commits-subscribe@magpie.apache.org) | [Unsubscribe](mailto:commits-unsubscribe@magpie.apache.org) | [commits archives](https://lists.apache.org/list.html?commits@magpie.apache.org) |

The Foundation-wide [announce@apache.org](mailto:announce@apache.org) list
carries announcements across Apache projects.
You can [subscribe](mailto:announce-subscribe@apache.org) or
[unsubscribe](mailto:announce-unsubscribe@apache.org).

## How to subscribe or unsubscribe

1. Send a plain-text email to the relevant subscribe or unsubscribe address above.
   A subject such as `subscribe` or `unsubscribe` is sufficient.
2. Check your inbox, including the spam folder, for an automated confirmation request.
3. Reply to that confirmation email to complete the request.

You normally need to subscribe before posting; otherwise your message may be
held for moderation.
See the [ASF mailing list guide](https://www.apache.org/foundation/mailinglists.html)
for details on managing subscriptions and list etiquette.

## Privacy and security

Messages to public lists are public and may be retained in archives.
Do not post credentials, unpublished vulnerabilities, or private project information.
For sensitive security reports, use the project's
[security reporting process](https://github.com/apache/magpie/security/policy)
instead of a public mailing list.
