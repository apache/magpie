# `path-unmatched` — an unknown area

A changed file matches neither allow list. Unknown paths are not assumed safe: the screen is conservative, and a missed trivial PR only waits for the next run.
Reported with its number, for `pr-management-code-review` ([`actions/hand-off.md`](../actions/hand-off.md)).
If the area really is supplementary, the fix is a new glob in `tier_a_allow_globs` / `tier_b_allow_globs`, not an exception in the conversation.
