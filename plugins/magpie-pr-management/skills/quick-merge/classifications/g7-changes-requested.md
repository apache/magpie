# `gate:G7` — a request for changes still stands

A reviewer's latest review is `CHANGES_REQUESTED`: their concerns are outstanding. A later push does not dismiss it — only the reviewer can, by approving or dismissing their review — so it blocks however old it is.
Gate drops are reported as counts; read this only when the maintainer asks why a PR is not a candidate. [`quick-merge screen`](../../../../../tools/pr-management/README.md#quick-merge-screen--pr-management-quick-merge) applied the gate.
