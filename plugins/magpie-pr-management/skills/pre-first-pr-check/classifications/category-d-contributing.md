# Category D failed — CONTRIBUTING conventions

A committed binary, an environment file, a token-like string, a large generated artefact, or a commit subject that describes the mechanics of the edit ("use sed to fix typo") rather than the user-visible change.
A committed credential must be **rotated**, not just removed: it is in the branch history.
Point the contributor at [`CONTRIBUTING.md`](../../../../../CONTRIBUTING.md) and the PR-body template.
