## Step 2 — Sequential per-PR review

The per-PR loop — headline, context, slop scan, body scans, findings, reviewer
suggestions, adversarial read, disposition, inline picker, body, SHA recheck,
post — is [`review-flow.md`](review-flow.md). Inline review comments are the
default output; a body-only review is the explicit `inline:off` exception.
