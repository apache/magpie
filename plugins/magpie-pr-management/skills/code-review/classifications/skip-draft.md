# Ask — the PR is a draft

Drafts never reach the default queue; a draft reached through `pr:<N>` asks first:

> *PR #N is a draft. Drafts are typically not reviewed yet. Continue anyway? `[Y]es`, `[S]kip`, `[Q]uit`.*
