# Disposition `COMMENT`

Everything that is neither: findings above `nit` without a gating count, CI pending or failing for reasons outside the diff, threads open, another maintainer's concern standing, or observations the maintainer wants to leave without gating the merge.
`approval_gates` in the result names exactly what kept `APPROVE` off the table — cite it in the summary: *"Approach looks reasonable; a few observations inline that I'd like resolved before merging — none blocking."*
