# Ask — approved earlier, new commits since

The viewer approved an older head; new commits have landed since. Ask, default skip:

> *PR #N has an earlier APPROVED from `<viewer>` against SHA `<old>`, but new commits have landed since (`<new>`). Want to re-review the delta? `[Y]es`, `[S]kip`, `[Q]uit`.*

The prior approval still counts toward GitHub's `reviewDecision`, which is why skipping is the default.
