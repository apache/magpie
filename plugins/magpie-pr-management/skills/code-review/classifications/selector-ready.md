# Selector `ready` — the curated triage queue

[`code-review`](../../../../../tools/pr-management/README.md#code-review--pr-management-code-review) sources PRs carrying the configured `ready for maintainer review` label, whoever is on the request list — the broader pool triage already deemed ready.
Usually combined with `area:<LBL>`; without it the pool is often too broad for one sitting.
