# Blocked — prep PR not merged

**Likely cause:** the prep PR is still open, or was closed without merge.

**Remediation:** merge the prep PR, or supply `--planning-issue` pointing at a planning issue where prep is confirmed.
Never advance past Step 0 while it is unmerged.
