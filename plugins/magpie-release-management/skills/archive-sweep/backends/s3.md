# Archive backend — `s3`

**Listing.** `aws s3 ls s3://<bucket>/<project>/` — each key prefix is a candidate.

**Archive.** One move per past-retention version, oldest first:

```text
aws s3 mv \
  s3://<bucket>/<project>/<ver>/ \
  s3://<archive-bucket>/<project>/<ver>/ \
  --recursive
```

The source is `release_dist_url_template` and the destination `archive_url_template` (required for `s3`),
each an `s3://<bucket>/…` URL or an `amazonaws.com` URL the bucket is read from; a template it cannot be read from is refused.
