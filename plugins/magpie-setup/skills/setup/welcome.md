# welcome — show a welcome guide, or turn one back on

`setup welcome [family]` is an alias for the
[`welcome-guide`](../welcome-guide/SKILL.md) skill
(`/magpie-setup:welcome-guide`, or `/magpie-setup-welcome-guide` on a pinned snapshot).
Run that skill with the same argument and follow it; nothing here repeats its steps.

Requests that land here include
*"show the security welcome again"*, *"turn the Magpie guide back on"*, and *"how do I start with Magpie"*.
